# Security policy

OSVA Monitor reads what is installed on your Mac and suggests commands to run, so a bug in it can mislead you or worse.
Please report anything that could (a wrong "not affected", a command that does something other than it says, data
leaving the Mac that the documentation says does not, a way for a file on disk or an API answer to run code) privately:

- **GitHub:** [Report a vulnerability](https://github.com/verificationalliance/osva-monitor/security/advisories/new)
  (private vulnerability reporting), or
- **Email:** contact@verificationalliance.org.

Please include the macOS version, the app version (Finder › Get Info on OSVA Monitor.app), and steps to reproduce.
We will credit you in the advisory unless you prefer otherwise.

Only the latest release is supported.
